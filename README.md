# FerexTCG Pro Site

Static pro animated website for GitHub Pages.

## Files
- index.html
- style.css
- script.js
- README.md

## How to use
1. Create a new public GitHub repo
2. Upload all files in this folder
3. Open `script.js`
4. Replace `https://form.jotform.com/YOURFORM` with your real JotForm link
5. In GitHub go to Settings -> Pages
6. Choose `Deploy from a branch`
7. Select `main` and `/ (root)`
8. Save

Your site will go live on GitHub Pages in about 1-2 minutes.
